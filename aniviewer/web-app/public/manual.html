Viewer Manual

Open your own game assets, explore animations, adjust sprites, and export the result. No desktop installation is required.

The manual opens separately so your current viewer session stays intact. Close this tab to return to it. Edits and IK setups are session-only: export your result before refreshing or changing animation, appearance, or files.

Quick start

  1. In Files, choose Open Game Folder. Select a folder containing the animation BIN/JSON files, atlas XML files, and matching images. Include the audio folder for sound.
  2. Alternatively, use Open Animation Files to select individual files or a ZIP containing the asset folders. A BIN alone usually cannot display the monster.
  3. Choose an Animation file, or open Monster Browser to find an indexed monster. Leave BIN revision on Automatic unless you know it was detected incorrectly.
  4. In Animation, select a track. Use Appearance when costumes are available.
  5. Press Play and Fit View. For edits, pause at a useful pose and open Sprites. To save an image or video, open Export.

Files & missing assets

The animation describes movement; the XML describes where sprites live on a sheet; the image supplies the pixels. Multiple sheets may be required for one animation. Keep original filenames and folder structure whenever possible.

  • Installed game plus downloads: import the game's data folder and its update/downloads folder if newer monsters or costumes live there. Importing only the installation can miss recent additions.
  • Monster Browser: searches the assets you have imported. It is not a download service for the main game's files.
  • Revisions: the selector includes Rev 1-6, Legacy Mobile, My Muppets Show, and Monster Choir. Change it only when appropriate for your files; a different revision cannot supply missing images.
  • Phones: if folder selection is unavailable, choose supported individual files or a ZIP from your device's file picker. Include the XML and spritesheets, not just the BIN.
  • Dawn of Fire: use Dawn of Fire Asset Grabber in Files, load a manifest, select bundles and use Download checked. Import the downloaded bundles if they were not added automatically. Related bundles may be needed for textures or audio. This operation requires a network connection.

Import assets you have the right to use. The public viewer does not ship with the game's monster asset library.

Remember your library

Enable Remember imported assets on this device in Files to retain local copies in this browser's IndexedDB storage. The viewer restores them on a later visit. This stores assets, not your transform edits or IK setup.

When your browser provides saved folder access, the viewer also remembers the folder handle and attempts to refresh it on startup. It may ask you to reconnect or grant permission. Use Refresh saved folders to check for changes yourself.

If folder handles are not available, the saved copy can still restore, but it cannot automatically read newer files from the original folder. Reimport changed files or a new ZIP to update it.

Forget saved library removes retained copies, not the originals on disk. Turning retention off also removes saved copies without discarding the current session. Browser storage can run out or be cleared; keep your original assets elsewhere. Private browsing and a different browser/device do not share this library.

Animation & costumes

Use Animation > Select Animation to choose a track such as Idle or Dance. Different tracks may use different spritesheets. The Appearance menu appears when matching costume definitions or DOF variants are indexed.

Costumes can require their own BIN/JSON definition, XML, images, shader sequence textures, and attached animation files. If a costume is missing or incomplete, import those dependencies as well as the base monster. A costume image by itself does not describe its layer swaps.

Costume selection applies remaps, clone layers, supported shader effects and attachments. Choose Base to return to the original appearance. Changing appearance resets session edits and links. Use the Layers panel to select or hide individual segments; its eye button changes visibility.

Transform sprites

  1. Select a segment in the viewport or Layers. Pause playback if you want a stable pose to work on.
  2. Choose Move and drag. For Rotate or Scale, drag the handle or drag the sprite horizontally.
  3. For precision, use the Sprites > Selected Sprites numeric fields, directional step buttons, rotation steps, scale axes, and Flip X / Flip Y.
  4. Use Undo, Redo, or Reset selected when needed. Escape cancels an active drag; arrow keys nudge and Shift increases the nudge.

Snap rounds drag amounts to the selected move step, 15-degree rotation steps, or 5% scale steps. It does not automatically connect sprite joints.

Without edit links, other segments do not inherit your edits. Your changes apply across the current animation while the original keyframes continue playing. Numeric fields show the edits you authored, not a decomposition of the final linked/IK pose. Image and video exports include these edits.

Not keyframe recording: these controls do not author new animation keyframes or save an editable project. Changing track, appearance, files, or refreshing clears the edits. Export a rendered result before leaving.

Link your edits

In Sprites > Edit Links, choose a Driver segment, then choose followers using Use animation descendants, Use selected segments, or the individual checkboxes. Hidden segments can also be followers.

  • Off - edit independently: future driver edits do not move followers.
  • Move together - all transforms: linked segments share the driver's edit. Selecting a member edits its driver. This is useful for a head with eyes, eyelids, mouth, and decoration.
  • Choose what follows: enable Follow movement, Follow rotation, and/or Follow scale. Members can still be edited independently.

Press Apply links. Rotation and scale move followers around the driver's anchor; group X/Y scaling uses world axes. The original animation still plays underneath, so links do not freeze animated expressions.

Important: changing a link preserves the current pose and affects the next edits. Switching Off does not undo previous linked edits. Use Undo or Reset selected for that. Links are animation-wide and session-only.

IK / limb bending

IK controls are currently in Sprites > IK / Limb Bending, not the placeholder Rigging tab. IK aims a single segment or bends a two-segment limb toward a target.

  1. Pause at a clear pose and expand Set up a new IK chain.
  2. Choose the chain type and its upper/root segment. For two segments, also choose the lower segment.
  3. Press Place root, then tap/click the root joint in the viewport. Place the bend and tip as appropriate. For two segments, the bend point belongs to both pieces.
  4. Choose any sprites that should follow each bone explicitly. Descendants and edit links are not added automatically.
  5. Press Create IK chain, enable it, and move the endpoint with its target controls or viewport handle.

Follow animation + offset keeps the animated target with your offset. Pin in world space holds the endpoint in place. Choose the original bend or a fixed side to control bending near a straight pose. The solver does not stretch bones: unreachable targets stop at the closest reach.

Turning Enable IK off removes that chain's solve and reveals the underlying animation and edits. This differs from Edit Links' Off mode. Undo includes IK setup and target changes. IK is included in rendered exports but is not saved as keyframes or an editable project.

Audio & playback

Import the matching audio assets with the animation. Audio is matched to the selected track; Idle and other silent tracks should stay silent rather than borrow an unrelated recording. My Muppets Show may also need its matching audio manifest.

Use Play, Loop and the timeline scrubber to preview. The Audio tab provides sound controls. On phones, start playback with a deliberate tap so the browser can allow audio. Keep the viewer in the foreground; the browser or operating system may suspend playback when backgrounded or locked.

If sound is silent or interrupted, pause and press Play again, check mute/volume, and check the displayed audio status. If the wrong track is selected or its asset is missing, import the correct audio rather than expecting the viewer to guess a substitute.

Export & save

Open Export after loading an animation. Exports include the current appearance, layer visibility, transforms, edit links, and IK.

Framing: Animation canvas uses the file's native dimensions. Stable content bounds measure the full animation to avoid changing crop sizes between frames. Choose resolution, frame rate, and optional background color in Frame Settings. GIF-specific settings are in Settings > Export > GIF.

Processing: Auto chooses an available video path. Fast uses WebCodecs and native encoding when supported. Compatibility records in real time, needs the tab visible, and takes at least the animation's duration. Use Auto or Compatibility if Fast is unavailable. A requested video format may still be unsupported on your browser; try Auto or another format.

Saving on phones: wait for Export Ready, then tap Save File. If offered, Share / Save to Files opens the device's share sheet. Open File provides another route. Keep the result open until saving finishes; Clear Result or refreshing releases it.

For large exports, reduce resolution or frame rate if you hit a memory/codec limit. Use Cancel Export to stop an in-progress job. Video audio follows the synchronized cycle when Include matched audio is checked, independently of preview mute.

Settings & home screen

The top-bar Settings button opens the settings drawer. Use its tabs for export, tools, asset paths, keybinds, and application options. Save to retain changes or cancel to discard the preview. Some desktop settings are marked partial or unavailable; their label describes what the web viewer currently supports.

You can add the public viewer to your device's home screen using your browser's Add to Home Screen or install action when offered. It uses the viewer icon. This does not grant automatic access to device folders, preserve unsaved edits, or guarantee audio playback while backgrounded.

Troubleshooting

Blank viewport, missing sprites, or a missing-texture error
Read the filename in the status message. Import the referenced XML and image, including secondary sheets. Use Fit View and check layer visibility. A BIN and an unrelated spritesheet are not enough.
A new costume does not appear
Add the game's downloads/update folder as well as the installation data. Include the costume definition, sheet, images, and any attachment animation. Then reselect the monster.
A saved library is old
Try Refresh saved folders. Reconnect when prompted. Without saved folder access, reimport the changed files or ZIP. Remembering a copy does not grant permission to reread the original folder.
My edits vanished
Edits, links and IK are session-only and reset on track/appearance/file changes or refresh. Asset retention does not save them. Export before leaving.
Export finishes but no file appears
Use the Export Ready buttons with a fresh tap. Try Share / Save to Files or Open File. Check your browser's downloads and device storage. Do not refresh until the file is saved.
Export cannot encode this format
Try Auto processing and format, or Compatibility. Lower resolution/frame rate. PNG, PNG ZIP, or GIF can be alternatives when the browser lacks a video codec.
Audio stops on a phone
Keep the viewer foregrounded, pause and tap Play again, and check mute/volume and audio status. An idle/silent track may intentionally have no sound.
A costume still looks different from the desktop viewer
Include the monster, costume and track names, asset version/revision, browser/device, a screenshot, and any status error in a report. Costume support has been expanded, but not every asset or browser has been visually verified.

Report an issue on GitHub (new tab). Avoid including personal paths or private files in a public report.

Limits & privacy

The browser viewer is still being brought toward desktop parity. Keyframe recording, editable project saves, animation BIN writing, PSD/After Effects rigs, transparent/ProRes video, batch-all-animation exports, layer-pass exports, terrain editing, and stereoscopic tools are not fully ported. A visible placeholder is not a working feature.

Imported assets are processed locally in your browser; importing does not upload them to this website. Remembered copies stay in that browser's storage. The hosted application and optional online tools still make network requests, including the DOF grabber and links you open. Original game files are not modified.

Keep a separate copy of your assets and save your exports. Browser storage and a home-screen installation are not backups.
